# Advertising & More — Job Vacancy & Careers Custom Concept

This is an original concept based on the public Advertising & More agency website, **not a generic jobs template**. It is intended as a high-fidelity custom Freelancer contest submission and a front-end implementation reference.

## Contest preview

Open `index.html` in a browser to explore the responsive page, animated coffee/career-themed 3D hero, company storytelling, refined navigation/footer and interactive form. Form inputs and CV selection are validated locally, **but preview mode does not transmit or store applications**.

## Submission graphics

The `contest-entry` folder contains JPG and PNG design presentation images matching the accepted Freelancer contest formats. Upload images to the contest; add source code only where supported or requested.

## Required form fields

Full name (as per IC), passport number for foreign applicants, date of birth, mobile number, current employer, earliest starting date (calendar picker), LinkedIn URL and upload resume/CV. Added email address, applicant type, optional area of interest and privacy consent to support a usable real application flow. File policy: PDF, DOC, DOCX, maximum 5 MiB.

## Backend / same development software

The public web view doesn't prove the site's exact CMS/framework. This package has framework-independent HTML/CSS/JavaScript plus an **optional WordPress plugin** in the `wordpress-plugin` folder. This does not claim the live agency site uses WordPress. Confirm the incumbent CMS, page builder and theme with the client before promising installation into the same software; adapt the supplied frontend to their actual stack if it differs. Real applications require deployment and a verified recruitment inbox/SMTP setup. The WordPress plugin is a reference backend and must be tested in the site's environment before going live.

## Brand fidelity

The design draws from the live site's recognizable **Click For Coffee**, **ROCK!**, **Under one happy roof**, warm yellow/orange/black styling and kinetic personality. The wordmark is a close concept rendition; replace it with the agency's original approved vector/brand artwork for production. All supplied illustrative assets are original generated design components.

## Browser & accessibility

Responsive layouts at 1440, 768 and 390 pixels. Keyboard-operable nav, focusable form inputs and conditional passport fields, native HTML dates, inline form errors, drag-and-drop file upload, accessibility-friendly reduced motion. Confirm final UX on physical devices and screen readers.
